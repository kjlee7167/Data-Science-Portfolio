Amazon Sales Analytics Dashboard

Overview

Developed an end-to-end e-commerce sales analytics project using MySQL and Tableau to transform raw transaction data into actionable business insights. The project involved cleaning and validating sales data, performing SQL-based exploratory analysis, calculating key business metrics, and building an interactive dashboard for executive reporting.

⸻

Objectives

* Clean and prepare raw sales transaction data
* Analyze sales performance across products, categories, regions, and time
* Calculate key business KPIs
* Build an interactive Tableau dashboard for business decision-making

⸻

Tools & Technologies

* MySQL
* Tableau
* SQL
* Window Functions
* Common Table Expressions (CTEs)

⸻

Project Workflow

1. Data Cleaning & Preparation

* Imported raw Amazon sales data into MySQL
* Converted incorrect data types
* Identified and handled missing values
* Validated data consistency
* Created cleaned analytical tables

⸻

2. SQL Analysis

Performed business-focused analysis including:

* Total Revenue
* Total Orders
* Average Order Value (AOV)
* Monthly Revenue Trends
* Revenue by Product Category
* Top Selling Products
* Revenue by State

Applied advanced SQL techniques such as:

* JOINs
* Aggregate Functions
* CASE Statements
* CTEs
* Window Functions
    * ROW_NUMBER()
    * RANK()
    * DENSE_RANK()
    * LAG()
    * LEAD()
    * SUM() OVER()

⸻

3. Tableau Dashboard

Designed an interactive executive dashboard featuring:

* KPI Cards
    * Total Revenue
    * Total Orders
    * Average Order Value
* Monthly Revenue Trend
* Revenue by Category
* Top 10 Products by Revenue
* Revenue by State (Filled Map)
* Interactive filters for data exploration
