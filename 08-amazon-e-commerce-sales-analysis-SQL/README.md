# Amazon E-Commerce Sales Analysis (SQL + Tableau)

## Project Overview

This project analyzes an Amazon e-commerce sales dataset to uncover sales performance, customer purchasing trends, and regional business insights. The analysis was performed using SQL for data cleaning and exploratory analysis, followed by Tableau to create an interactive executive dashboard.

The goal was to simulate a real-world business intelligence workflow by transforming raw transactional data into meaningful insights that support data-driven decision-making.

---

## Project Objectives

- Clean and prepare raw sales data using SQL
- Analyze revenue, orders, and product performance
- Identify regional and category sales trends
- Apply advanced SQL techniques including joins, CTEs, and window functions
- Build an interactive Tableau dashboard for executive reporting
