# Predicting Zestimate Price Factors using Zillow and Census Data

Data Science Capstone Project

## Overview

This project analyzes how socioeconomic and regional factors influence Zillow home value estimates (ZHVI) and rental price trends across the United States.

Using Zillow housing datasets and U.S. Census data, we explored relationships between population density, poverty rates, migration patterns, and housing market behavior.

---

## Research Questions

1. How do poverty rates and population density affect Zillow home value estimates?

2. How did COVID-related migration and economic shifts influence rental price growth?

---

## Methods

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Linear Regression
- Random Forest
- Histogram Gradient Boosting
- PCA
- K-Means Clustering

---

## Technologies

Python  
pandas  
NumPy  
scikit-learn  
Matplotlib

---

## Results

- County-level models explained ~72% of variance
- City-level models explained ~35% of variance
- Population density strongly impacted housing values
- Migration patterns influenced rental growth
