# Spotify Hit Song Prediction

Machine Learning project predicting song popularity using Spotify audio features.

## Overview

This project builds predictive models to determine whether a song becomes a hit using Spotify audio characteristics.

The goal was to identify which features contribute most to popularity.

---

## Methods

- Data Cleaning
- Feature Engineering
- Classification
- Class Imbalance Handling
- Model Evaluation

Models:
- Neural Network
- Random Forest

---

## Technologies

Python  
pandas  
scikit-learn

---

## Results

- Random Forest achieved strongest performance
- ROC AUC ≈ 0.96
- High recall on hit song prediction
