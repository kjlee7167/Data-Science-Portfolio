# Tourism in Japan: COVID-19 and Exchange Rate Analysis

Analyzing how COVID-19 and economic factors influenced tourism patterns in Japan.

## Overview

This project explores changes in tourism activity in Japan before, during, and after the COVID-19 period.

The analysis investigates whether factors such as exchange rate fluctuations and pandemic-related conditions influenced visitor volume and tourism recovery.

---

## Objective

- Analyze tourism trends over time
- Compare tourism activity across COVID periods
- Investigate the relationship between exchange rates and tourism demand
- Evaluate factors influencing tourism recovery

---

## Dataset

Tourism and economic datasets including:

- Monthly visitor statistics
- Exchange rate information (Japanese Yen)
- Time-based tourism indicators

---

## Methods

### Data Preparation
- Data Cleaning
- Time Segmentation
- Missing Data Handling

### Exploratory Data Analysis
- Tourism Trend Analysis
- Country Comparison
- COVID Period Comparison

### Statistical Modeling
- Linear Regression
- Correlation Analysis

---

## Technologies

R

---

## Key Findings

- Tourism activity declined significantly during COVID-19 periods
- Recovery trends appeared after travel restrictions eased
- Exchange rate changes alone had limited explanatory power
- External events had stronger influence than currency fluctuations
