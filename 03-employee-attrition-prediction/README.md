# Employee Attrition Prediction

Predicting employee turnover using machine learning.

## Overview

Built predictive models to identify employees likely to leave a company using HR analytics.

---

## Dataset

IBM HR Analytics Dataset

Features:
- Income
- Satisfaction
- Overtime
- Years at Company

Target:
- Attrition

---

## Methods

- One-Hot Encoding
- Feature Scaling
- Logistic Regression
- Random Forest

---

## Technologies

Python  
pandas  
scikit-learn

---

## Results

- Logistic Regression outperformed Random Forest
- AUC ≈ 0.85
- Attrition strongly associated with overtime and satisfaction
